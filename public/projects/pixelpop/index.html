Seni Bina Elektronik

Spesifikasi Perkakasan & Pemetaan Pin

Seni bina perkakasan PixelPop menggunakan gabungan Cytron Maker ESP32 yang dicucuk di atas papan Robo ESP32 (Stack Architecture). Gabungan ini memberikan akses serentak kepada piezo buzzer, LED diagnostik, 2x NeoPixel RGB terbina, 3 butang onboard sedia guna, suis kuasa fizikal, serta litar pengecasan bateri.

⚡ Fasa 1: Ujian Serta-Merta (3 Butang Onboard — Pilihan 3)

Uji seluruh logik permainan, warna lampu NeoPixel, dan sintesis audio 8-bit serta-merta tanpa perlu menunggu butang luaran tiba.

Komponen Ujian Onboard Papan Asal & Pin GPIO Peranan / Fungsi Tindakan Pemain
Sasaran 1 (Warna Merah) Maker ESP32 · GPIO 4 (Input Pull-up) Sasaran Refleks 1 + Nada C5 (523Hz) Tekan butang onboard Maker ESP32 apabila lampu merah menyala
Sasaran 2 (Warna Kuning/Biru) Robo ESP32 · GPIO 34 (Input Pull-up) Sasaran Refleks 2 + Nada E5 (659Hz) Tekan Butang 1 pada papan Robo ESP32
Sasaran 3 (Warna Hijau) Robo ESP32 · GPIO 35 (Input Pull-up) Sasaran Refleks 3 + Nada G5 (784Hz) Tekan Butang 2 pada papan Robo ESP32
Penunjuk Visual (2x RGB) Robo ESP32 · GPIO 15 (WS2812B) Menyala warna sasaran aktif / animasi kejayaan 2x NeoPixel onboard berkelip & berubah warna
Sintesis Bunyi (Buzzer) Maker ESP32 · GPIO 26 (Built-in Piezo) Kesan nada 8-bit, klik, bunyi terlepas & melodi menang Pastikan suis gelongsor buzzer Maker ESP32 pada kedudukan ON

Nilai Permainan (Play Value)

3 Mod Permainan Interaktif

1. Speed Pop (Whack-a-Mole)

Satu butang akan menyala secara rawak. Kanak-kanak perlu memukul butang tersebut sebelum masa tamat (1.5 saat hingga 0.5 saat).

  • Menguji koordinasi mata dan tangan (*hand-eye coordination*).
  • Kelajuan bertambah setiap 5 pukulan tepat.
  • 3 peluang sebelum Game Over.

2. Memo Pattern (Simon Says)

Mainan akan memainkan urutan lampu dan nada (contoh: Merah $\rightarrow$ Hijau $\rightarrow$ Biru). Kanak-kanak perlu mengulangi urutan dengan tepat.

  • Melatih ingatan jangka pendek dan fokus kanak-kanak.
  • Panjang corak meningkat dari 3 hingga 12 langkah.
  • Melodi kemenangan dimainkan apabila melepasi pusingan 8.

3. Free Beats (DJ / Piano Soundboard)

Mod santai untuk kanak-kanak kecil berumur 3–4 tahun. Setiap butang menghasilkan nada muzik harmoni dan lampu yang menenangkan tanpa sebarang had masa.

  • Sesuai untuk kanak-kanak prasekolah meneroka bunyi.
  • Tiada tekanan kalah/menang.
  • Animasi lampu pelangi apabila dua butang ditekan serentak.
Integriti Mekanikal & Keselamatan

Garis Panduan Reka Bentuk 3D & Keselamatan Kanak-kanak

Berikut adalah lakaran visual konsep industri dan gambarajah pemasangan letupan (exploded assembly CAD) untuk PixelPop. Reka bentuk ini dioptimumkan khas untuk pencetakan 3D FDM (Creality K1 / Ender / SparkX) dengan mengambil kira faktor ketahanan hentakan dan ergonomik kanak-kanak berumur 4–8 tahun.

🎮 Rupa Bentuk Pod Permainan (Visual Render)

Permukaan condong 12° ke hadapan, 4 butang kubah arked bercahaya (Merah, Kuning, Hijau, Biru), bucu lembut filleted, dan gril pembesar suara piezo di tengah.

📐 Gambarajah Letupan CAD (Exploded Assembly)

Susun atur modular 3-lapisan: Penutup atas (Top Housing Ø30.5mm), casis pengikat dalaman (Maker ESP32 + Robo ESP32 Stack), dan tapak bawah bersama petak bateri selamat.

Firmware Perisian

Kod Sumber Arduino (Maker ESP32 + Robo ESP32 Stack)

Pilih kod firmware mengikut fasa pembangunan anda. Anda boleh menguji gameplay serta-merta menggunakan 3 butang onboard sebelum memasang butang arked fizikal ke dalam pod 3D.

⚡ 1. Kod Ujian Serta-Merta (3 Butang Onboard — Pilihan 3) Perlukan library Adafruit NeoPixel (Maker ESP32 dicucuk atas Robo ESP32, tanpa wayar luar).
PixelPop_Onboard_Stack_Test.ino 
// =========================================================================
// PixelPop - Onboard Buttons Prototype Test (No External Wiring Needed)
// Hardware: Cytron Maker ESP32 stacked on Cytron Robo ESP32
// Target: Domechy Maker Challenge x Creality 2026
// =========================================================================

#include <Arduino.h>
#include <Adafruit_NeoPixel.h>

#define BUZZER_PIN       26   // Maker ESP32 Onboard Piezo Buzzer
#define NEOPIXEL_PIN     15   // Robo ESP32 Onboard 2x NeoPixels
#define NUM_PIXELS       2

// 3 Butang Onboard pada Stack
#define BTN_MAKER        4    // Butang Maker ESP32 (Pull-up LOW pressed)
#define BTN_ROBO1        34   // Butang 1 Robo ESP32 (Pull-up LOW pressed)
#define BTN_ROBO2        35   // Butang 2 Robo ESP32 (Pull-up LOW pressed)

const int buttonPins[3] = {BTN_MAKER, BTN_ROBO1, BTN_ROBO2};
const int noteFreqs[3]  = {523, 659, 784}; // Nada C5, E5, G5

Adafruit_NeoPixel strip(NUM_PIXELS, NEOPIXEL_PIN, NEO_GRB + NEO_KHZ800);

int currentTarget = -1;
int score = 0;
unsigned long spawnTime = 0;
unsigned long timeLimit = 1500; // Mulai dengan 1.5 saat

void playTone(int freq, int durationMs) {
  tone(BUZZER_PIN, freq, durationMs);
  delay(durationMs);
  noTone(BUZZER_PIN);
}

void showColor(uint32_t color) {
  for (int i = 0; i < NUM_PIXELS; i++) {
    strip.setPixelColor(i, color);
  }
  strip.show();
}

void spawnNewTarget() {
  currentTarget = random(0, 3);
  spawnTime = millis();

  // Tunjukkan warna sasaran pada NeoPixel Robo ESP32
  if (currentTarget == 0) {
    showColor(strip.Color(255, 0, 0));   // MERAH -> Butang Maker ESP32 (GPIO 4)
  } else if (currentTarget == 1) {
    showColor(strip.Color(255, 200, 0)); // KUNING -> Butang Robo 1 (GPIO 34)
  } else {
    showColor(strip.Color(0, 255, 0));   // HIJAU -> Butang Robo 2 (GPIO 35)
  }

  playTone(noteFreqs[currentTarget], 80);
}

void setup() {
  Serial.begin(115200);
  Serial.println("PixelPop Onboard Stack Test Bermula!");

  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(BTN_MAKER, INPUT_PULLUP);
  pinMode(BTN_ROBO1, INPUT); // GPIO 34 ada perintang pull-up perkakasan pada Robo ESP32
  pinMode(BTN_ROBO2, INPUT); // GPIO 35 ada perintang pull-up perkakasan pada Robo ESP32

  strip.begin();
  strip.setBrightness(60);
  strip.show();

  // Animasi & Nada Permulaan
  for (int i = 0; i < 3; i++) {
    showColor(strip.Color(0, 150, 255));
    playTone(523 + (i * 130), 100);
    showColor(strip.Color(0, 0, 0));
    delay(80);
  }

  randomSeed(analogRead(36));
  spawnNewTarget();
}

void loop() {
  // Semak jika pemain menekan sebarang butang
  for (int i = 0; i < 3; i++) {
    if (digitalRead(buttonPins[i]) == LOW) {
      if (i == currentTarget) {
        score++;
        Serial.print("TEPAT! Skor: ");
        Serial.println(score);
        showColor(strip.Color(0, 255, 255)); // Kilat Biru Tanda Tepat
        playTone(noteFreqs[i], 120);

        if (timeLimit > 450) timeLimit -= 40; // Semakin laju
        delay(120);
        spawnNewTarget();
      } else {
        Serial.println("SALAH BUTANG!");
        showColor(strip.Color(255, 0, 0));
        playTone(180, 200); // Nada terlepas
        delay(150);
        spawnNewTarget();
      }
      break;
    }
  }

  // Had masa refleks tamat
  if (millis() - spawnTime > timeLimit) {
    Serial.println("MASA TAMAT!");
    playTone(150, 180);
    showColor(strip.Color(80, 0, 0));
    delay(120);
    spawnNewTarget();
  }
}
🎮 2. Kod Pod Arked Penuh (4 Butang Luaran — Pilihan 4) Untuk pemasangan akhir bersama 4 Arcade Button, NeoPixel Ring, & Maker ESP32 stack.
PixelPop_Arcade_Pod_Full.ino 
// =========================================================================
// PixelPop - 4 Arcade Buttons Interactive Pod (Whack-a-Mole + Sound FX)
// Hardware: Cytron Maker ESP32 stacked on Robo ESP32
// Pins: Buttons {13, 14, 27, 32}, Mode {4}, NeoPixel {15}, Buzzer {26}
// =========================================================================

#include <Arduino.h>
#include <Adafruit_NeoPixel.h>

#define BUZZER_PIN    26  // Maker ESP32 Piezo Buzzer
#define MODE_BTN_PIN  4   // Maker ESP32 Onboard Button
#define NEOPIXEL_PIN  15  // Robo ESP32 NeoPixel / NeoPixel Ring
#define NUM_LEDS      4   // Atau 8/12 jika guna cincin NeoPixel

// 4 Butang Arked Luaran (Panel Mount 30mm)
const int btnPins[4] = {13, 14, 27, 32}; // Merah, Kuning, Hijau, Biru
const int tonesList[4] = {523, 659, 784, 1046}; // C5, E5, G5, C6

Adafruit_NeoPixel strip(NUM_LEDS, NEOPIXEL_PIN, NEO_GRB + NEO_KHZ800);

int currentScore = 0;
int activeTarget = -1;
unsigned long targetSpawnTime = 0;
unsigned long reactionTimeout = 1200;

void playTone(int freq, int durationMs) {
  tone(BUZZER_PIN, freq, durationMs);
  delay(durationMs);
  noTone(BUZZER_PIN);
}

void playMissTone() {
  playTone(200, 180);
}

void highlightButton(int idx) {
  strip.clear();
  if (idx >= 0 && idx < 4) {
    uint32_t colors[4] = {
      strip.Color(255, 0, 0),   // Merah
      strip.Color(255, 200, 0), // Kuning
      strip.Color(0, 255, 0),   // Hijau
      strip.Color(0, 120, 255)  // Biru
    };
    strip.setPixelColor(idx, colors[idx]);
  }
  strip.show();
}

void spawnNewTarget() {
  activeTarget = random(0, 4);
  highlightButton(activeTarget);
  targetSpawnTime = millis();
}

void handleButtonPress(int index) {
  if (index == activeTarget) {
    currentScore++;
    playTone(tonesList[index], 120);
    if (reactionTimeout > 400) reactionTimeout -= 30; // Semakin responsif
    delay(80);
    spawnNewTarget();
  } else {
    playMissTone();
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(MODE_BTN_PIN, INPUT_PULLUP);

  for (int i = 0; i < 4; i++) {
    pinMode(btnPins[i], INPUT_PULLUP);
  }

  strip.begin();
  strip.setBrightness(70);
  strip.show();

  // Startup Sound
  for (int i = 0; i < 4; i++) {
    highlightButton(i);
    playTone(tonesList[i], 100);
    delay(50);
  }
  spawnNewTarget();
}

void loop() {
  for (int i = 0; i < 4; i++) {
    if (digitalRead(btnPins[i]) == LOW) {
      handleButtonPress(i);
      delay(180); // Debounce
      break;
    }
  }

  if (millis() - targetSpawnTime > reactionTimeout) {
    playMissTone();
    spawnNewTarget();
  }
}
